Agent Response:
Implemented the complete Live GPS Telemetry and Ephemeral Single-Use Secure Tracking Link system for high-value cargo:

1. **Schema Enhancements (`src/backend/schema.sql`)**:
   - `shipment_telemetry`: Stores live GPS stream (`latitude`, `longitude`, `speed_kmh`, `heading_degrees`, `battery_pct`, `timestamp`), linked to `shipment_id` and courier `recorded_by_id`.
   - `tracking_tokens`: Stores ephemeral single-use access links. Uses `token_hash TEXT PRIMARY KEY` (SHA-256 digest), `expires_at`, `is_used`, `used_at`, and `used_ip`. Raw tokens are never stored in the database.

2. **Customer Ephemeral Link Generation (`src/backend/shipments.py`)**:
   - `POST /api/shipments/<id>/generate-tracking-link`: Customer can generate a single-use tracking link for high-value cargo with configurable TTL (5-60 minutes). Generates a 32-byte URL-safe cryptographic token (`secrets.token_urlsafe(32)`), computes SHA-256 digest, and stores the digest. Enforces customer ownership (returns 404 anti-probing on foreign shipments).
   - `GET /api/shipments/<id>/telemetry`: Retrieves full GPS coordinate trail for shipment owner or admin.

3. **Courier Live GPS Ingestion (`src/backend/delivery.py`)**:
   - `POST /api/delivery/shipments/<id>/telemetry`: Assigned courier records GPS coordinates. Validates latitude (-90 to 90) and longitude (-180 to 180), numeric speed, heading, and battery levels. Rejects submissions for terminal states (`Delivered`, `Cancelled`). Enforces assignment isolation (returns 404 and logs `UNAUTHORIZED_SHIPMENT_ACCESS` on cross-courier attempts).

4. **Public Single-Use Tracking Endpoint (`src/backend/tracking.py`)**:
   - `GET /api/tracking/live/<token>`: Public endpoint requiring no login. Validates incoming token by computing SHA-256 digest. Enforces strict anti-replay protection by burning the token immediately (`is_used = 1`). Second access attempts return HTTP 410 Gone (`TOKEN_ALREADY_USED`) and log `REPLAY_ATTACK_DETECTED`. Expired tokens return HTTP 410 Gone (`TOKEN_EXPIRED`) and log `EXPIRED_TRACKING_TOKEN`. Returns shipment metadata, latest GPS coordinates, and milestone audit log.
   - Registered `tracking_bp` in `src/backend/app.py`.

5. **Automated Test Suite (`tests/test_gps_and_ephemeral_token.py`)**:
